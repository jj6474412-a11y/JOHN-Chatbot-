# JOHN-Chatbot-
fully responsive, single-page AI chatbot built with HTML, Tailwind CSS, and vanilla JavaScript. It uses the Gemini API with Google Search grounding to provide real-time, factually accurate answers and automatically cites its sources.
John's AI Chat: A Grounded Gemini Chatbot
​This is a minimalist, single-file web application for a modern, responsive chat interface powered by the Gemini API with Google Search grounding.
​The application is built to be easily deployed on services like GitHub Pages due to its single-file structure (index.html).
​✨ Features
​Real-time Grounding: Uses the Gemini API's Search Tool to access real-time information from Google Search, ensuring responses are factual and up-to-date.
​Automatic Source Citation: Provides clear citations (links and titles) for the web sources used to generate the AI's response.
​Mobile-First Design: Fully responsive layout built with Tailwind CSS, providing a clean experience on any device.
​Conversation Context: Maintains and uses chat history for coherent, multi-turn conversations.
​Reliable API Calls: Implements exponential backoff logic for robust handling of network issues and rate limiting.
